# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, keep to the topic, and do not harass or
demean anyone. The maintainer may remove comments or contributions that break
these rules.

To report a problem, use the maintainer's GitHub profile or the private
vulnerability form on the Security tab.
