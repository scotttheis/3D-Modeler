# R2d WRL evidence

## Scope

R2d implements the authoritative `L:\Builder3D\src\wrl_io.py` export
boundary in the Rust core. WRL is export-only in the Python product; Rust
keeps that contract and returns a typed unsupported-format error for import.

## Implemented behavior

- Writes VRML 2.0 UTF-8 with Builder3D millimetre coordinates.
- Exports each scene item as a `Transform`/`Shape` pair with translation,
  rotation, non-uniform scale, sanitized unique `DEF` names, comments, and
  indexed triangular geometry.
- Preserves RGBA display colors as `diffuseColor` and VRML transparency,
  including the Python default mesh color and six-decimal color rounding.
- Validates finite meshes, finite affine transforms, non-singular transforms,
  orthonormal rotation decomposition, and rejects shear with typed errors.
- Uses bounded object, vertex, face, and output-byte limits.
- Writes path exports through a completed temporary file and replacement,
  preserving the previous output when validation fails.
- Adds `.wrl` format selection to the generic mesh boundary while rejecting
  WRL import explicitly.

## Golden/reference evidence

`tests/fixtures/wrl/python_reference.wrl` is a two-box document generated by
the Python exporter. Rust reproduces it byte-for-byte, including face order,
transform fields, names, colors, transparency, and final newline.
