# RB-04 numeric, selection and focus contracts

Single-object numeric Move changes the world position, Rotate sets absolute XYZ Euler degrees while retaining signed stretch/shear, and Resize changes world dimensions while retaining the translation column. Multiple selection follows the Python TransformBar: Move positions the combined AABB center; Rotate applies the requested angle minus the first scene object's displayed angle around the combined center; Resize scales the combined world bounds around their center. Hidden selected objects participate. Scene order supplies the displayed first object; Align/Arrange retain user anchor order.

The three numeric fields support mm/in display, degree angles, Apply/Enter and Escape restoration. The proportional lock uses the field actually edited, including Y/Z and small changes; viewport object alignment changes the resize box, while numeric sizes stay world dimensions. Invalid active fields preserve every target and history. Inactive transform fields do not block an edit. Name editing is shown for one selected object.

Plain Items and viewport hits toggle additively, matching the reference. Items Shift ranges resolve the anchor by durable ID, so deleting an earlier row does not redirect the range. Empty viewport clicks clear unless Sticky Selection or Ctrl/Command preserves them. Scene insertion/removal now remaps selection order together with indices; undo/redo retain the original anchor identities. Membership checks avoid quadratic selection-order scans.

Editing shortcuts are blocked by a focused text editor, file/placement/measurement/save-confirmation/overwrite modal, ribbon customization, or an open menu. The egui focus regression uses a real TextEdit and raw key events; it proves Delete/Cut/Paste/Duplicate/Undo/Select All preserve geometry while typing. Unfocused Delete remains undoable. Viewport motion cancels on Escape, focus loss, modal capture or a changed scene. All 14 visible face/corner Resize handles start the adapter gesture, and a click without motion changes neither pose nor history in both bases.

`numeric-selection-oracle.json` records 32 calls to the actual Python TransformBar multi-selection method, using a minimal non-window adapter. `placement-oracle.json` records 42 real TransformService operations covering all mirror axes, align landmarks, arrangement gaps (0, 5, 10000 mm), and both ordinary/reversed anchor orders. Rust compares all original matrices within 0.003, checks one-action undo/redo, and preserves hidden state and identity. Grouped clipboard/duplicate/delete tests include fresh descendant IDs, names, hidden children, offsets and undo/redo. The focused Python scene run passes 25 tests.
