## Route scope

The Python reference exposes Material/Paint/Color on its Paint tab and sample-image color through its favorite alias/command. Rust's three visible Paint commands dispatch to the same Material dialog. File menu > Print Prep Check and the top 3D Print utility are separate actions. No RB-07 code changes the favorite/pinning/settings system, which belongs to RB-08.
